Install the APK

  1. Tap Download Android APK above.

Or install as a PWA (no download)

  1. Open the web app in Chrome on Android.
  2. Tap the menu ⋮, then Install app or Add to Home screen.
  3. Tap Install. The app icon appears on your home screen.

iPhone / iPad: open the web app in Safari, tap Share, then Add to Home Screen, then Add. There is no App Store version.

About these downloads — please read

The web app works right now, in any browser, with all lessons, the AI Tutor and the microphone speaking practice. Your progress is saved in your browser.

The Android APK, Windows installer and macOS DMG are built automatically by this repository’s GitHub Actions (Capacitor for Android, Electron for Windows and macOS) when a change is pushed to the main branch. They appear in the latest release once that build finishes — please allow a few minutes after a new release, and check the Releases page if a download link does not open yet. The Android APK is signed with an ephemeral signing key unless a release keystore is set in the repository secrets.
